Project (.fe3d) Recommended

Native project file. Carries the scene as it stands — every object with its mesh, materials and modifiers, the cameras and lights, the timeline and every keyframe — and opens back into this app with nothing lost.

🟩
Project (.fe3a) Same project

The same complete project written with the companion tag, for builds and tools that look for .fe3a. This app opens either one.

📂
Open project (.fe3d, .fe3a) Import

Open a project file back into the workspace. Older .final3d files open too — they carry the camera, lighting and animation, but no meshes.

🌐
GLTF / GLB (.glb, .gltf) Web / Games / DCC

Standard WebGL & 3D real-time interchange format. Supported by Blender, Unreal Engine, Unity, Web, and Godot.

📦
Wavefront (.obj) Geometry / CAD

Universal multi-polygon mesh geometry file with vertex positions, normals, and UVs. Compatible with all 3D modeling and CAD tools.

🎬
Filmbox (.fbx) Animation / Pipeline

Industry-standard 3D asset interchange format with node hierarchies, materials, transforms, and mesh topologies.
